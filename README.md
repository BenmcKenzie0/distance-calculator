# Distance Calculator

A travel utility for calculating distance from speed and time.

## Features

- Speed input
- Travel duration
- Distance in multiple units

## How to Use

Enter average speed and travel time.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
